## Update the SAME GitHub repository

1. Open your existing resume website repository in a computer browser. Keep a copy of the original files before updating.
2. Replace its existing HTML and CSS with the supplied files. If the original uses another CSS folder or filename, preserve that structure and adjust the HTML stylesheet link accordingly. Do not remove unrelated files.
3. Use GitHub's Add file > Upload files to upload the extracted website files, or edit the existing files manually. Commit the changes. Do not upload the ZIP itself as the website.
4. If GitHub Pages is already configured, retain its working publishing branch and folder. Upload the updated files to that source folder.
5. If Pages is not configured, open Settings > Pages > Build and deployment. Select Deploy from a branch, choose the branch containing the files (commonly main), choose /(root) if index.html is at the top level, then Save. If using an existing /docs source, retain /docs and put the files there.
6. Wait for deployment to finish. Copy the actual published address from Settings > Pages > Visit site. Do not use a github.com file-view URL as the live website address.
7. Open the published site in a fresh browser tab and verify styling, navigation, and smaller-screen layout. If it fails, inspect the repository's Actions tab and check file paths and case.

The root of the selected publishing folder must contain `index.html` and, for this supplied layout, `style.css`. A project site's address is commonly https://USERNAME.github.io/REPOSITORY/; use the actual address GitHub supplies.
